# AlphaTab MusicXML Rendering Limitations

Living document tracking known AlphaTab quirks and unsupported MusicXML elements.
Updated as edge-case corpus tests reveal rendering discrepancies.

**AlphaTab version:** 1.8.1 (stable) / latest (next)
**Last updated:** 2026-06-01

---

## Unsupported / Partially Supported MusicXML Elements

| Element | Status | Notes |
|---------|--------|-------|
| `<backup>` / `<forward>` | ⚠️ Partial | Interleaved staves with time-axis jumps work in basic cases. Complex multi-voice interweaving may produce misaligned notes. See [alphaTab#949](https://github.com/CoderLine/alphaTab/issues/949). |
| Multi-measure rests | ❌ Not supported | `<rest measure="yes">` renders as a whole rest, not a multi-bar rest symbol. See [alphaTab#495](https://github.com/CoderLine/alphaTab/issues/495). |
| Nested tuplets | ⚠️ Partial | Standard 3:2 tuplets render correctly. Non-standard ratios (e.g., 12:27) may cause crashes on Android (ClassCastException). See [alphaTab#2630](https://github.com/CoderLine/alphaTab/issues/2630). |
| Percussion notation | ⚠️ Partial | Basic percussion staves render. Complex instrument articulations may not map correctly. See [alphaTab#762](https://github.com/CoderLine/alphaTab/issues/762). |
| `<sound>` attributes | ⚠️ Partial | `tempo` is respected. `dynamics`, `damp`, and other playback attributes are ignored for audio synthesis. |
| Grace notes | ⚠️ Partial | Basic grace notes render. Complex grace note groups with multiple acciaccaturas may overlap. |
| `<grouping>` / `<linked>` | ❌ Not supported | Structural grouping elements are ignored. |
| `<visitor>` / `<bookmark>` | ❌ Not supported | Navigation elements are ignored. |
| Chord diagrams (`<frame>`) | ✅ Supported | Rendered as fretboard diagrams below the staff. Works with `<frame-note>` including `<mute>` for unused strings. |
| `<dynamics>` | ✅ Supported | Rendered as standard dynamics markings (pp, p, mp, mf, f, ff). |
| `<articulations>` | ✅ Supported | Staccato, accent, tenuto render correctly. |
| `<slur>` | ✅ Supported | Legato slurs render with correct start/stop. |
| `<technical>` | ✅ Supported | String/fret indicators render below the staff. |
| `<beam>` | ✅ Supported | Beams group by beat structure. Cross-beam beams are not generated by our builder. |
| `<defaults>` layout | ✅ Supported | Scaling, page-layout, system-layout are respected by AlphaTab. |

## Platform-Specific Differences

| Behavior | Web | Android | iOS |
|----------|-----|---------|-----|
| Standard MusicXML rendering | ✅ | ✅ | ✅ |
| Nested tuplets (non-standard ratios) | ✅ | ❌ ClassCastException | ⚠️ Untested |
| Complex multi-voice interleaving | ⚠️ | ⚠️ | ⚠️ |
| Chord diagrams (`<frame>`) | ✅ | ✅ | ✅ |
| `<dynamics>` markings | ✅ | ✅ | ✅ |

## Test Reference for Upstream Bug Tracking

When a corpus file fails to render or produces visual discrepancies:

1. Check the AlphaTab GitHub issues for known bugs
2. File an upstream issue if the MusicXML is spec-compliant but AlphaTab misrenders
3. Document the discrepancy here with the AlphaTab issue number
4. Add a regression test in `musicxml-rendering.spec.ts` with `@skip` tag if needed
